# Publishing checklist

## Before publishing

1. Confirm that the professor has marked the topic as approved in the spreadsheet.
2. Read the Medium article once and adjust any wording you want to express differently.
3. Verify your name, course, and source links.

## Medium

1. Create a new Medium story.
2. Copy the content from `article/medium-article.md`.
3. Upload the six images from `images/` at the marked figure locations.
4. Preserve every figure caption and source link.
5. Use the title `When Data Changes: How Autonomous Systems Learn from Concept Drift`.
6. Suggested tags: `Data Mining`, `Machine Learning`, `Concept Drift`, `Data Streams`, and `Continual Learning`.
7. Publish the story and copy its public URL into the main README.

## SlideShare

1. Upload `presentation/autonomous-drift-learning.pdf` or the PowerPoint file.
2. Suggested title: `Autonomous Drift Learning in Data Streams`.
3. Use the article introduction as the description.
4. Add the paper links in the SlideShare description.
5. Copy the public SlideShare URL into the main README.

## Video

1. Present the 14-slide deck using `narration/presentation-script.md`.
2. Aim for 10–15 minutes. The script supports approximately 12–14 minutes at a natural pace.
3. Record at 1080p and verify that text remains readable.
4. Export an MP4 or upload the recording to YouTube.
5. Add the file or public link to the GitHub repository and README.

## GitHub

1. Create a public repository such as `cmpe255-autonomous-drift-learning-short-story`.
2. Upload the contents of this package, keeping the folder structure unchanged.
3. Replace all `ADD_...` placeholders in `README.md`.
4. Open the repository in a private browser window to verify public access.
5. Test the Medium, SlideShare, spreadsheet, paper, and video links.
6. Submit the GitHub repository URL to the professor.
